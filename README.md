## Alder University Campus Store Kiosk (`AlderUni`)

An interactive portrait kiosk interface (1024 × 1440) for Alder University's campus store, built with React 19, TypeScript, and Vite.

### Features
- **Student ID Authentication & Registration:** Sign in with 8-digit student card or register a new student account with starting balance and Hawks rewards points.
- **Full 25-Product Catalog:** Real-time category filtering (All, Apparel, Accessories, Everyday, Balance & rewards).
- **Interactive Product Details:** Size selection, real-time inventory checking (e.g. XL out-of-stock handling), and quantity adjustments.
- **Dynamic Shopping Cart:** Live price calculations, 5% campus tax, points calculation, item removal, and empty state handling.
- **Campus Payment & Rewards:** Checkout via Campus Balance or Card, 2-second authorization spinner, pickup code generation, and 500-point reward redemption (₱100 store credit).

### Getting Started

```bash
cd AlderUni
npm install
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) to view the kiosk.

### Production Build

```bash
cd AlderUni
npm run build
```
